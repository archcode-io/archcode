# ArchCode for VS Code

Syntax colouring, bracket matching, folding and comment toggling for `.arch` files —
[ArchCode](https://archcode.io), an open notation for software architecture.

The grammar is generated from the reference engine's vocabulary (`node build.mjs`), so
kinds, verbs and attribute keys are the parser's own list.

Coming: diagnostics inline, id completion, a live preview pane.

Apache-2.0 · ArchCode is an open standard created and maintained by Baryshev Labs.
